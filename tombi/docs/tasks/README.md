# ערכת משימות חדשות לטומבי

1. בפרויקט שלך ב-VS Code, יוצרים תיקייה `docs/tasks/` ומעתיקים אליה את `tasks-spec.md` ואת `claude-code-prompt-tasks.md`.
2. ב-Claude Code כותבים: "Read docs/tasks/claude-code-prompt-tasks.md and do it, phase by phase."
3. אחרי כל שלב (A עד F) Claude Code עוצר ומסביר מה לבדוק. כדאי לבדוק במצב סימולציה ורק אז להמשיך.
4. `gemini-prompt-tasks.md` הוא הפקודה ל-Gemini לניסוח השורות, הווידאו והתמונות.
